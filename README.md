# Yeishin

Yeishin is a music player for the Yabbyville crowd: a fork of
[Feishin](https://github.com/jeffvli/feishin) with Yabbyville stickers on top.
macOS and Windows.

- Yabbyville stickers sit on album covers where people placed them, with their
  messages beside the track list.
- A **Yabby** page lists recently stickered albums, and a "Yabby stickers" row
  can be added to the home page.
- Everything else (Navidrome, Jellyfin and OpenSubsonic servers, MPV and web
  players, lyrics, smart playlists, remote control) is Feishin's.

It installs beside stock Feishin, with its own app id, settings and updates.

## Install

Download the latest release from
[Releases](https://github.com/hamsterona/yeishin/releases/latest), then follow
the steps in [YEISHIN.md](YEISHIN.md#install) (unsigned builds need one extra
click on first launch).

## Problems

- Something to do with stickers, the Yabby page, tokens or updates:
  [open an issue here](https://github.com/hamsterona/yeishin/issues).
- Something that also happens in stock Feishin: report it to
  [Feishin](https://github.com/jeffvli/feishin/issues).
